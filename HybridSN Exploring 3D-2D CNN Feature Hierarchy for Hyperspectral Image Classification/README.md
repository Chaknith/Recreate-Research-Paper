# HybridSN 
[Exploring 3D–2D CNN Feature Hierarchy for Hyperspectral Image Classification](https://arxiv.org/abs/1902.06701)

This paper teaches you how to handle spectral-spatial cubes, patch extraction, and standard HSI benchmarks. The paper reports experiments on Indian Pines, Pavia University, and Salinas, and its abstract points to public code.

Official github repository:
- Tensorflow version: https://github.com/gokriznastic/HybridSN
- Pytorch version: https://github.com/Pancakerr/HybridSN

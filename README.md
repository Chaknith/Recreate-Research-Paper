# Recreate Research Paper

This repository contains recreations of research papers, including implementation notes, experiment results, and benchmark comparisons.

## Recreated Papers

### 1. [HybridSN: Exploring 3D–2D CNN Feature Hierarchy for Hyperspectral Image Classification](<HybridSN Exploring 3D-2D CNN Feature Hierarchy for Hyperspectral Image Classification/>)
Original Paper <https://arxiv.org/abs/1902.06701>

Reimplemented and evaluated the HybridSN architecture for hyperspectral image classification, with additional experiments examining PCA leakage, validation-based model selection, and random versus spatial data splitting.
